  ❌ Admin and ShopLayout rendering together (duplication)
  ❌ Non-professional URL structure

  ✅ Role-based access control

================================================================================
BACKWARD COMPATIBILITY
================================================================================

OLD BOOKMARKS STILL WORK:
  /app/admin?tab=overview  →  Redirects to  →  /app/admin/overview
  /app/admin?tab=menu      →  Redirects to  →  /app/admin/menu
  ... (all 10 tabs mapped)

How it works:
  1. User visits old ?tab= URL
  2. LegacyTabRedirect catches it
  3. Converts to new path
  4. Redirects with replace=true
  5. User continues normally
